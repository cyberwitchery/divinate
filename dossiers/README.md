# test evidence

this directory contains retained evidence used by the product-level provenance
tests. it is test data, not a tutorial or a current assessment. generated dossiers
and views are intentionally not checked in.

the directory is excluded from the published crate because its content-addressed
blobs exceed the package size limit.

root `.evidence/` remains local and ignored. the repository's committed
`divinate.yaml` drives operational dogfooding, while this directory retains only
selected canonical regression evidence whose size and review purpose justify
checking it in.
